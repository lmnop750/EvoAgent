# 模块化目录与迁移说明

整理日期：2026-10-02。

本次将原来平铺的 53 个业务 Python 文件分入 12 个子包，并同步调整测试、脚本和文档位置。业务行为保持不变；应用入口仍为 `python -m evoagent`。这不是通过批量转发文件隐藏旧目录，而是真正移动实现并更新调用方。

## 模块职责

| 子包 | 职责 | 主要入口 |
|---|---|---|
| `application` | HTTP 和应用服务 | `api.py`、`service.py` |
| `core` | 共享数据与配置 | `config.py`、`models.py`、`diff_parser.py` |
| `agents` | 多角色审查、模型调用、取证工具与报告 | `agentic_core.py`、`llm.py`、`repository_tools.py` |
| `runtime` | 执行、恢复、审批、事件、证据与产物 | `runtime.py`、`harness.py`、`journal.py` |
| `memory` | 上下文、检索、记忆治理与反馈 | `context_manager.py`、`memory.py` |
| `evolution` | 候选诊断、回放、租约、发布与监控 | `evolution_pipeline.py`、`candidate_store.py` |
| `evaluation` | 计分、数据构造与消融 | `evaluation_harness.py`、`evaluation_v2.py` |
| `storage` | SQLite / PostgreSQL | `store.py`、`postgres_store.py` |
| `integrations` | GitHub 集成与认证 | `github.py`、`auth.py` |
| `skills` | Skill 加载与演进 | `skills.py`、`skill_evolution.py` |
| `repair` | 补丁与验证 | `fixer.py`、`patching.py`、`verifier.py` |
| `infrastructure` | 消息队列、监控与追踪 | `task_queue.py`、`observability.py` |

子包初始化文件不集中导入业务类，避免额外循环依赖和隐式初始化。调用方明确导入实现模块，例如：

```python
from evoagent.application.service import ReviewService
from evoagent.runtime.runtime import AgentRuntime
from evoagent.storage.store import TaskStore
```

旧的 `evoagent.service` 等平铺导入路径已迁移，外部自写脚本也需要按此规则修改。项目内的测试、mock 目标与延迟导入已同步调整。

## 非代码文件

- `tests/` 按模块分组，`tests/support/` 保存共享模拟模型，`tests/ui/` 保存浏览器检查。
- `scripts/benchmarks/` 放本地机制基准，`scripts/evaluation/` 放评测和数据工具，`scripts/maintenance/` 放布局检查。
- `data/benchmarks/` 保存可公开受控样本。
- `docs/project/`、`docs/design/`、`docs/interview/`、`docs/benchmarks/`、`docs/assets/` 分别保存项目长文、设计、面试资料、结果和图片。
- `web/`、根目录 `skills/` 和 `evolution-data/` 保留原路径，以保持 Compose 挂载与本地配置兼容。
- `.env`、`.venv` 和现有数据库保留在原工作区，不进入上传副本。

Markdown 内仓库文件链接改为相对路径，便于 GitHub 浏览。历史 PDF 为原始资料，未改写其中的旧路径。没有随项目分发的外部个人参考文档只保留文字说明。

## 资源路径与检查

移动文件时同步修正了配置加载器寻找根目录 `.env` 的层级、API 静态资源路径、脚本定位仓库根目录的层级、测试 Skill 目录与浏览器测试的前端目录。

在仓库根目录执行：

```bash
python -B scripts/maintenance/check_layout.py
python -m unittest discover -s tests -t . -v
```

第一条检查 Python 语法、全部业务模块导入、六个脚本的帮助入口、静态资源及 Markdown 本地链接，不调用模型。第二条运行已有测试，PostgreSQL 专项依赖显式提供专用测试连接。

原工作区 `tmp/layout-before-20261002.zip` 保留迁移前源文件快照（不含虚拟环境、密钥配置或数据库），`tmp/layout-mapping.json` 保存路径映射。两者仅供本地回查，不进入公开副本。

## GitHub 副本范围

副本包含源码、测试、工具、Web / Skill 资源、公开受控样本、配置模板和全部项目文档。不复制真实 `.env`、私钥、数据库、缓存、IDE 配置、日志、临时产物、虚拟环境或外部评测数据。此目录整理未创建远端仓库、推送代码或选择开源许可证。
